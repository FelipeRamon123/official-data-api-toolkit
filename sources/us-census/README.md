## Quick start: Power Query

1. Open Excel or Power BI.
2. Create a blank query.
3. Open **Advanced Editor**.
4. Paste one of the files in `power-query/`.
5. Replace `YOUR_CENSUS_API_KEY`.

Most examples accept multiple years:

```powerquery
Years = {2024, 2025}
```

or:

```powerquery
Years = {2020..2025}
```

## Quick start: Python

From the repository root:

```bash
python -m pip install -r requirements.txt
```

Set your Census API key:

```powershell
$env:CENSUS_API_KEY="YOUR_CENSUS_API_KEY"
```

or on macOS/Linux:

```bash
export CENSUS_API_KEY="YOUR_CENSUS_API_KEY"
```

Then run, for example:

```bash
python sources/us-census/python/02_all_countries_by_htsus10.py --years 2024 2025
```

Port and HS6 for Brazil:

```bash
python sources/us-census/python/03_country_by_port_and_hs6.py \
  --years 2024 2025 \
  --country-code 3510 \
  --output data/brazil_port_hs6.csv
```

U.S. exports to Brazil by Schedule B10 and export type:

```bash
python sources/us-census/python/06_exports_to_country_by_schedule_b10.py \
  --years 2024 2025 \
  --country-code 3510 \
  --output data/us_exports_to_brazil_schedule_b10.csv
```

## What else can the API do?

The six scripts are examples, not the full API.

The Census API also supports dimensions such as:

- customs district;
- U.S. state of destination;
- NAICS;
- End-Use;
- Advanced Technology;
- USDA classifications;
- country subcodes;
- transport measures;
- quantities and units.

See [`docs/query-options.md`](docs/query-options.md).

## Important concepts

### Annual data

The examples use `MONTH = 12` with fields ending in `_YR`.

Example:

```text
GEN_VAL_YR
CON_VAL_YR
DUT_VAL_YR
CAL_DUT_YR
```

These are year-to-date measures. In December, they represent the complete calendar year.

### General imports vs. imports for consumption

They are not the same measure.

A shipment can arrive in the United States and be recorded in general imports before it is withdrawn from a bonded warehouse or Foreign Trade Zone for consumption.

See the practical definitions in [`docs/data-dictionary.md`](docs/data-dictionary.md).

### HTSUS10 vs. HS6

The main `imports/hs` endpoint supports `COMM_LVL=HS10`, which corresponds to the U.S. 10-digit statistical classification used here as **HTSUS10**.

Port and state HS endpoints are limited to HS2, HS4 and HS6.

### HTSUS10 vs. Schedule B10

U.S. imports use HTSUS statistical codes at the 10-digit level. U.S. exports use Schedule B codes. Both share the international HS base through six digits, but their 10-digit extensions are not interchangeable.

Example 06 uses `E_COMMODITY`, `ALL_VAL_YR` and `DF`. The `DF` field distinguishes domestic exports (`1`) from foreign merchandise exported from the United States (`2`), commonly described as re-exports.

### Large queries

Trying to request every country and every detailed product in one call can time out.

Example 02 uses a safer pattern:

```text
get country list
→ query one country
→ repeat
→ append results
```
